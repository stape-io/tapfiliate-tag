# Tapfiliate tag for Google Tag Manager Server Container

Tapfiliate tag for Google Tag Manager Server Container allows you to seamlessly integrate Tapfiliate affiliate tracking with your server-side setup using their REST API.

## Features

- **Page View**: Automatically extracts the referral parameter from the URL, generates a Click ID via the Tapfiliate API, and stores it in a first-party cookie (`_tapfiliate_cid`).

- **Conversion**: Sends conversion data securely to Tapfiliate.

- **Optimistic Scenario**: Optionally speed up sGTM response times by returning tag success immediately without waiting for the Tapfiliate API response.
